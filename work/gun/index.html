Mid-Poly 베이스와 POM Mesh Decal로 제작한 최종 Hero Asset, Color Variant와 애니메이션 팀용 슬롯 표시 제어 결과입니다.

문제와 제약

Roulette Pistol은 라이브 콘텐츠에서 화면에 크게 노출되는 Hero Prop이므로, 작은 크기 안에서도 실루엣과 하드서페이스 디테일이 명확하게 읽혀야 했습니다. 동시에 슬롯 표시부의 좌·중·우 상태와 Trigger 위치를 샷별로 변경해야 했기 때문에, 애니메이션팀이 Mesh나 Material Graph를 직접 수정하지 않고 조절할 수 있는 제어 구조가 필요했습니다.

해결 방식

실루엣과 주요 구조는 Weighted Normal 기반 Mid-Poly Mesh로 제작하고, 패널 경계·체결부·접합부처럼 반복되는 표면 디테일은 POM이 적용된 공용 Mesh Decal Library로 분리했습니다. Shared Trim·Tile Material과 Decal을 조합해 고유 Texture 의존도를 줄이고, Sci-fi Car와 Train에 사용한 동일한 제작 규칙을 적용했습니다.

Slot Display Blueprint

Animation Input → Trigger Movement / Left·Middle·Right Slot State / Emissive → Custom Primitive Data & Material Parameters → Final Presentation

좌·중·우 슬롯 값을 전용 Blueprint Function에서 화면용 Custom Primitive Data와 Material Parameter로 변환하도록 구성했습니다. Screen Material은 CPD 기반 UV Offset과 세 개의 Emissive Color 채널을 처리하므로, 작업자는 Material Graph를 열지 않고 슬롯 심벌·색상·발광 상태를 조절할 수 있습니다.

Trigger는 0–1 범위의 입력값을 상대 위치로 변환하도록 분리했습니다. 슬롯 표시와 Trigger Pose를 Blueprint 입력으로 제공해, 애니메이션·연출 작업자가 샷에 필요한 상태를 에셋 내부 수정 없이 설정할 수 있도록 했습니다.

내 기여

  • Roulette Pistol Hero Asset 모델링
  • 공용 Mid-Poly + POM Mesh Decal Workflow 적용
  • Shared Trim·Tile Material과 Asset-Specific Material Instance 구성
  • 슬롯 Screen Material과 Custom Primitive Data 기반 UV·Emissive 제어
  • 좌·중·우 Slot State 및 Trigger Movement Blueprint 제작
  • 애니메이션·콘텐츠 제작팀용 최종 Actor 세팅

작동 방식

Base Mid-Poly Mesh → Shared Trim / Tile Material → POM Mesh Decal Library → Asset-Specific Material Instance → CPD Display Control → Animation-Ready Blueprint

형태를 담당하는 Mesh와 표면 디테일, 슬롯 표시 제어를 분리해 디자인 수정과 재사용이 가능하도록 구성했습니다.

Production Handoff

최종 에셋은 Mesh와 Material만 전달하지 않고, 슬롯 표시 상태·발광 강도·Trigger 위치를 작업자가 직접 조절할 수 있는 Blueprint Actor 형태로 제공했습니다.
