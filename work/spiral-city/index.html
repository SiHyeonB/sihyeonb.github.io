문제와 제약

Spiral City는 Vista 전역에 반복 건물이 넓게 노출되는 장면이었습니다. 건물을 개별 Actor와 Component로 계속 추가하면 반복 수에 따라 관리 항목과 Triangle 비용이 장면 전체에 누적되므로, 도시 밀도와 실루엣을 유지하면서 반복 유형과 거리에 맞춰 리소스 구조를 구분할 필요가 있었습니다.

또한 동일한 건물군 안에서도 Window와 Color Variation이 필요했지만, 이를 위해 Material Instance를 건물마다 복제하면 반복 배치의 이점이 줄어듭니다. 원경에 반복되는 Road Lamp 역시 실제 볼륨 Mesh를 계속 배치하지 않고 형태와 깊이를 읽히게 만드는 방식이 필요했습니다.

Vista Assembly & Optimization

Building Set → Blueprint Generation → Instance / Merge → Distance LOD

Blueprint에서 건물군을 절차적으로 생성하고, 반복되는 Mesh는 Instanced Static Mesh로 구성했습니다. 반복 배치는 Instance로 묶고 고정된 배치군은 Merge해, Vista를 구성하는 Actor와 Component의 관리 단위를 용도에 따라 나눴습니다.

원경 건물에는 거리별 LOD를 적용해 카메라에서 읽히는 도시 실루엣은 유지하면서 Triangle 비용을 조절했습니다. 자동 생성 이후에도 필요한 배치와 형태를 보정할 수 있도록 구성해, 최적화 구조가 Level Art의 수정 가능성을 제한하지 않도록 했습니다.

Building CPD Control

Variation Values → Generated Component → CPD Float / Vector → Shared Material

건물 생성 단계에서 Window와 Color Variation 값을 구성하고, 생성된 Component에 Custom Primitive Data의 Float·Vector 값으로 전달했습니다. Material은 Component별 CPD를 읽어 표현을 변경하므로, 건물마다 별도의 Dynamic Material Instance를 만들지 않고도 공용 Material 안에서 Variation을 제어할 수 있습니다.

2 Tri POM Road Lamp

2 Tri Plane → 512² Packed Map → POM / Pixel Depth Offset → Road Lamp

Vista 전역에 반복되는 Road Lamp는 형상을 2 Tri Plane으로 단순화했습니다. 512² Packed Map 기반 Parallax Occlusion Mapping과 Pixel Depth Offset으로 표면 깊이와 형태감을 재구성해, 실제 볼륨 Geometry를 반복하지 않고도 촬영 구도에서 Lamp의 입체감이 읽히도록 했습니다.

내 기여

  • Instance·Merge·LOD 기준을 적용한 Vista 건물군 구성
  • Blueprint 기반 건물 생성과 Instanced Static Mesh 배치
  • 생성 Component용 Custom Primitive Data Variation 전달
  • 2 Tri Plane과 512² Packed Map 기반 POM Road Lamp 제작
  • 최적화 구조를 반영한 Spiral City Level Art 조정

검증·성과

도시의 반복 밀도와 원경 실루엣을 유지하면서, 반복 건물은 Instance·Merge로 관리하고 거리별 LOD로 Triangle 예산을 조절했습니다. 건물 Variation은 Material Instance 증식 없이 CPD로 전달했으며, 반복 Road Lamp의 Geometry 예산은 개체당 2 Tri로 고정했습니다.
