컨셉 아트가 없는 상태에서 시작하여 배경의 방향성을 구체화하고, 라이팅을 제외한 배경 제작 전반을 단독 담당했습니다. 원형 도시를 빠르게 반복 구성할 수 있도록 Spline 기반 건물 배치와 Road Track 제작 Blueprint를 개발하고, 모듈형 배경 제작과 Level Art에 적용했습니다.

Role
Environment Design · Level Art · Spline-Based Blueprint · Asset/Material 제작

Technical breakdown

Spiral City의 최종 Level Art와 Spline 기반 Building Blueprint, Road·Vista·Hologram의 적용 결과입니다.

문제와 설계

원형 도시에는 동일한 건물과 도로 모듈이 넓은 범위에 반복되지만, 단순 복제만으로는 곡률과 카메라 구도에 맞는 실루엣을 유지하기 어렵습니다. 초기 배치는 자동화하면서도 모듈별 위치·회전과 전체 경로를 직접 조정할 수 있는 제작 구조가 필요했습니다.

Blueprint Systems

Spline-Based Modular City

Spline Input → Transform Sampling → Seeded Mesh Selection → Component Generation → Custom Primitive Data Assignment

Construction Script가 Spline의 진행 거리에 따라 Location과 Rotation을 샘플링하고, Mesh Array에서 Seed 기반으로 건물 모듈을 선택합니다. 선택된 모듈은 Static Mesh Component로 생성되어 Spline의 곡률을 따라 배치되므로, Spline 형태를 수정하는 것만으로 건물군의 진행 방향과 전체 실루엣을 다시 구성할 수 있습니다.

Mesh·Location·Rotation Array와 Spline Scale을 분리해 자동 배치 이후에도 요소별 Transform과 모듈 종류를 직접 보정할 수 있도록 했습니다. Random Stream을 사용해 같은 Seed에서는 동일한 결과가 유지되므로, Variant를 만들면서도 배치 상태를 재현할 수 있습니다.

생성된 Component에는 Float와 Vector4 형식의 Custom Primitive Data를 전달해, 별도의 Dynamic Material Instance를 여러 개 만들지 않고도 Material에서 컴포넌트별 값을 사용할 수 있는 경로를 구성했습니다.

Hierarchical Rotation Control

Time Input → Rotation Speed → Pivot Local Rotation

전체 구조와 Spline 건물군, 원형 구조물을 각각 Pivot_All, Pivot_Spline, Pivot_Circle 계층으로 분리했습니다. 공통 Time Input과 그룹별 Rotation Speed를 기준으로 Pivot의 Local Rotation을 갱신해, 개별 Mesh Transform을 다시 계산하지 않고도 구조물 그룹의 회전 연출을 제어할 수 있도록 했습니다.

Spline-Based Road Track

Spline Length / Module Length → Segment Count → Spline Mesh Generation → Location·Tangent·Scale·Roll Sampling

도로의 길이와 곡률을 반복해서 수작업으로 맞추지 않도록, Spline을 따라 모듈형 Road Mesh를 구성하는 Construction Script 기반 Blueprint를 제작했습니다. 전체 Spline 길이와 Road Module 길이로 필요한 Segment 수를 계산한 뒤 각 구간에 Spline Mesh Component를 생성합니다.

각 Segment의 시작·끝 지점에서 Location과 Tangent, Scale, Roll을 샘플링해 Mesh의 곡률과 뱅킹을 갱신합니다. Spline Point나 Roll을 수정하면 도로가 경로에 맞춰 다시 구성되므로, 긴 Track의 형태를 비파괴적으로 반복 조정할 수 있습니다.

내 기여

  • Spline Sampling과 Seed 기반 모듈 선택을 결합한 Building Blueprint 제작
  • 요소별 Mesh·Location·Rotation 보정 및 Spline Scale 제어 구조
  • 생성 Component용 Custom Primitive Data 전달과 계층형 회전 제어
  • Segment 자동 계산과 곡률·Scale·Roll을 반영하는 Road Track Blueprint 제작
  • Blueprint 결과를 기반으로 한 Spiral City Level Art 조정

결과

건물군과 Road Track을 개별 배치하는 대신 Spline과 제한된 입력값으로 재구성할 수 있게 했습니다. 자동 생성 결과를 요소별로 보정할 수 있어 반복 제작 속도와 Art Direction을 함께 유지했으며, 같은 규칙을 도시 원경과 주요 주행 구도에 재사용했습니다.
