컨셉 아트가 없는 상태에서 시작하여 배경의 방향성을 구체화하고, 라이팅을 제외한 배경 제작 전반을 단독 담당했습니다. Seed 기반 Candy Variant Blueprint와 개체별 색상·발광 제어, 표면 특성별 Material Library를 제작했습니다.

Technical breakdown

Candy Land의 최종 Level Art와 Candy Color·Emissive Variation, POM Moss 및 Camera-Facing Card Material의 적용 결과입니다.

제작 범위

완성된 컨셉 아트가 없는 상태에서 공간의 방향과 동선을 구체화하고, 라이팅을 제외한 3D 에셋·Texture·Material·Level Art·Blueprint 제작 전반을 담당했습니다.

문제와 설계

형태와 색상이 다른 Candy Prop이 장면 전반에 반복되므로, 각 조합마다 별도 Mesh Actor와 Material Instance를 만들면 수정 범위가 빠르게 늘어납니다. 반복 요소의 형태·색상·발광은 공통 입력으로 변형하면서, Candy·Cake·Moss·Vista처럼 표면 특성이 다른 요소는 용도별 Material Family로 분리할 필요가 있었습니다.

Blueprint & Material Systems

Seeded Candy Variant Blueprint

Mesh Type·Seed → Seeded Variant Selection → Palette / Manual Color → Custom Primitive Data → Candy Material

하나의 Candy Blueprint에서 Stick과 Sphere 타입을 선택하고, 각각 5종과 2종의 Mesh 후보군에서 Seed가 적용된 Random Stream으로 Variant를 결정하도록 했습니다. 같은 Seed에서는 선택 결과가 유지되어 배치 상태를 재현하면서 필요한 인스턴스만 변형할 수 있습니다.

색상은 Red·Green·Blue·Purple·Yellow Palette 또는 Manual Color로 지정하고, Color와 Emissive Intensity를 Custom Primitive Data(CPD)의 Vector3·Float 값으로 Material에 전달합니다. Dynamic Color와 Intensity 입력은 사용 여부를 분리해, 값 갱신이 필요한 시점에 선택적으로 반영할 수 있도록 구성했습니다.

Candy & Dessert Shading

Candy·Cake·Macaron은 전용 Subsurface Profile과 Fresnel, Detail Normal, Roughness 제어를 조합해 부드러운 산란과 표면 반응을 조절했습니다. Sugar Detail은 World-Aligned Noise로 분리해 크기가 다른 에셋에서도 패턴 밀도를 유지하고, Cake Pattern·Metal Relief·Ice Cream Cone의 굴곡은 Parallax Occlusion Mapping(POM)과 Pixel Depth Offset으로 표현했습니다.

Moss & Vista Materials

Moss는 POM Base, Masked Card, Translucent Color Overlay의 세 계층으로 분리하고 공통 Base·Edge Color 로직을 공유했습니다. 표면 굴곡과 외곽 실루엣을 서로 다른 계층에서 조절해 근접 화면과 넓은 배경 배치에 함께 대응하도록 했습니다.

원경 Card에는 Vertex Shader 기반 카메라 방향 변형(WPO), Depth/FOV 기반 Mask와 World-Space Color Overlay를 적용했습니다. 카메라 방향과 장면 색에 맞춰 Card의 실루엣과 색상을 조정할 수 있도록 구성했습니다.

Ring Pop Stage Assembly

외부 Thin Translucent Ring과 내부 Opaque Mesh를 각각 분리하고 하나의 Blueprint Actor로 구성했습니다. 복잡한 제어 로직을 추가하기보다 두 파트를 재사용 가능한 Stage 배치 단위로 묶고, 파트별 렌더링 설정은 독립적으로 관리했습니다.

결과

반복되는 Candy Prop은 하나의 Blueprint와 공통 Material 경로 안에서 형태·색상·발광을 변형하고, 표면 특성이 다른 요소는 기능별 Material Family로 분리했습니다. 이를 통해 장면의 컬러와 실루엣을 개별 조정하면서도 동일한 제작 규칙으로 Variation을 관리할 수 있었습니다.
