Technical breakdown

Weighted Normal Mid-Poly 베이스메시와 POM Mesh Decal을 이용한 히어로 에셋 제작. 러프한 컨셉아트만 주어진 상태에서 Pre-viz 등이 진행될 때마다 크고 작은 수정이 매번 필요한 워크플로우였기 때문에, Vertex Normal을 조정하여 제작하는 Mid-poly 와 프로젝트 전체에 사용되는 POM Decal 을 이용하여 수정을 용이하게 만듬. 유니크 텍스처는 글자와 같이 해당 에셋에서만 사용될 요소만 Atlas 화 하여 한 세트만 사용하고 일반적인 표면에는 유니크 텍스처를 사용하지 않음. 프로젝트 전반에 사용되는 공용 노이즈, 재질 디테일 텍스처만 일부 사용하여 최적화함. 내부 조명이나 컬러 등을 실시간을 조절할 수 있도록 Custom Primitive Data를 이용하여 Draw count, Material Slot, 개별 에셋의 숫자를 줄여 최적화함.

문제와 제약

대형 열차의 실루엣과 내부 공간을 빠르게 제작하면서도 패널 경계, 접합부, 볼트와 Trim 같은 하드서페이스 디테일을 충분히 표현해야 했습니다. 모든 디테일을 고유 Mesh와 Texture로 제작하면 수정 비용과 리소스 사용량이 크게 증가합니다.

해결 방식

실루엣과 주요 구조는 Mid-Poly Mesh로 제작하고, 반복되는 표면 디테일은 POM이 적용된 Mesh Decal 라이브러리로 분리했습니다. 공용 Decal과 Material을 조합해 고유 Texture 의존도를 낮추고, 동일한 디테일 세트를 다른 Hero Asset에서도 재사용할 수 있도록 했습니다.

내 기여

  • Mid-Poly + Mesh Decal Workflow 설계
  • POM 기반 공용 Mesh Decal과 Material 제작
  • Sci-fi Train 외부·내부 Hero Asset 제작
  • 반복 가능한 패널·Trim·접합부 디테일 구성
  • 애니메이션 및 콘텐츠 제작팀용 Blueprint 세팅
  • 실시간 사용을 고려한 Material과 리소스 구조 정리

작동 방식

Base Mid-Poly Mesh → Shared Trim / Tile Material → POM Mesh Decal Library → Asset-Specific Material Instance → Animation-Ready Blueprint

형태를 결정하는 Mesh와 표면 디테일을 분리해 수정과 재사용이 가능하도록 구성했으며, 최종 에셋은 다른 팀이 바로 배치하고 조작할 수 있는 Blueprint 형태로 제공했습니다.
