Environment Production

RnD Environment Scene - Alley

2020

Environment ProductionLevel ArtAsset ArtMaterial ArtProcedural Generation

Unreal Engine 4의 정적 라이트 베이킹 환경을 기준으로 짧은 제작 기간 안에 완성한 사내 R&D Alley Scene입니다. Level Art와 일부 프랍 제작, 모듈형 리소스 구성, 프로시주얼 배치와 공용 Material을 담당하고 Lightmap·리소스 재사용을 고려해 장면을 구성했습니다.

Role
Level Art · 일부 프랍 제작 · Modular Environment · Procedural Placement · Material
Project
Internal UE4 Environment R&D
Engine
Unreal Engine 4

문제와 제약

전통적인 Static Lighting과 Lightmap Bake를 사용하는 UE4 환경에서, 짧은 제작 기간 안에 골목 장면의 공간 구성과 Bake 품질을 확보해야 했습니다. 에셋을 구역마다 개별 제작하면 제작량과 Bake 관리 범위가 빠르게 늘어나므로, 제한된 리소스를 반복 사용하면서도 공간의 깊이와 시선 흐름을 유지할 제작 방식이 필요했습니다.

설계·구현

건축 파츠와 배경 소품은 반복 조합할 수 있는 모듈 단위로 구성하고, 동일 리소스가 연속해서 보이지 않도록 배치 간격·회전·스케일과 표면 Variation을 조정했습니다. 반복 요소는 프로시주얼 배치 방식으로 보조하고, 넓은 표면은 공용 Tiling Material과 Parameter 조합으로 운영했습니다.

조명은 실시간 가변 효과보다 Static Lighting과 Lightmap 품질에 집중했습니다. 장면의 주요 시선과 명암 구간을 Level Art 단계에서 먼저 정리하고, 제한된 프랍·모듈·Material을 재사용해 제작 범위와 Bake 부담을 함께 관리했습니다.

내 기여

  • Alley Scene Level Art와 공간 구성
  • 일부 건축·배경 프랍 제작
  • 반복 조합을 위한 모듈형 리소스 구성
  • 프로시주얼 배치와 공용 Material 적용
  • Static Lighting·Lightmap 환경을 고려한 장면 최적화

결과

짧은 R&D 제작 흐름 안에서 제한된 모듈과 공용 Material을 재사용해 골목 장면을 완성했습니다. 실시간 조명 비용을 늘리지 않고 Bake 기반 명암과 공간 깊이를 확보했으며, Level Art·프랍·프로시주럴 배치·Material 작업을 하나의 제작 규칙으로 연결했습니다.
