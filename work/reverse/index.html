Technical breakdown

전체 구동에서 외곽 기어 트레인과 중앙 메커니즘까지, Orrery 세트의 다층 회전 구조를 단계별로 보여 줍니다.

제작 범위

라이팅을 제외한 Orrery 배경 제작 전반을 담당했습니다. 다층 기어와 행성 궤도, 중앙 시계 장치의 Asset·Material 제작과 Level Art를 진행하고, 각 파트가 하나의 장치처럼 움직이도록 Gear Parent와 Stage Blueprint를 구성했습니다.

문제와 설계

서로 다른 축·반지름·속도를 가진 회전 부품이 여러 층에 중첩된 구조였습니다. 각 Mesh의 움직임을 개별 애니메이션으로 관리하면 수정 지점이 분산되고, 전체 동작의 위상과 리듬을 샷에 맞춰 조율하기 어려웠습니다.

물리 시뮬레이션 대신 이 공통 Time Input을 기준으로 각 파트의 Transform을 계산했습니다. 같은 시간축은 유지하되 파트별 속도·시작 각도·높이와 수동 각도를 노출해, 일관된 기계 운동과 아트 디렉션에 필요한 제어 범위를 함께 확보했습니다.

Blueprint 구동 구조

Shared Time Input (Material Parameter Collection) → Gear Parent / Stage → Speed·Offset·Manual Override → Pivot-Based Relative Transform

Stage와 Gear Parent는 서로를 직접 호출하지 않고 같은 Time Input을 각각 참조합니다. Stage는 중앙 기어 그룹과 시·분·초침을, Gear Parent는 다단 기어와 두 개의 Planet Ring, Planet A–G 모듈을 담당합니다. 각 파트가 개별 Timeline을 갖는 대신 같은 시간축에 기어별 배율과 회전 방향을 적용해 장치 전체의 운동을 맞췄습니다.

각 기어 그룹은 Scene Component를 회전축으로 사용하는 계층형 Pivot 구조로 구성했습니다. Gear Parent에서는 링과 행성별 Speed·Start Offset·Height·Visibility를 조절할 수 있으며, 필요한 경우 자동 회전을 끄고 Manual Rotation 값으로 개별 각도를 고정할 수 있습니다. 행성 높이 값은 Relative Location과 Custom Primitive Data에 함께 전달해 Transform과 Material이 동일한 제어값을 참조할 수 있도록 했습니다.

내 기여

  • 라이팅을 제외한 Orrery Environment Asset·Material·Level Art 제작
  • 다층 기어·행성 궤도·중앙 시계 장치의 Pivot 계층 설계
  • Gear Parent / Stage Blueprint 구동 로직 제작
  • Material Parameter Collection의 Scalar Parameter를 공통 Time Input으로 구성
  • 파트별 Speed·Offset·Manual Override 구성
  • 행성별 Height·Visibility·CPD 연동

결과

기어와 행성, 시계 장치를 개별 애니메이션 자산으로 분리하지 않고 하나의 공통 Time Input과 노출 파라미터로 제어할 수 있게 했습니다. 이를 통해 샷 구성이나 장면 수정 시 전체 메커니즘의 리듬을 유지하면서도 파트별 동작과 배치를 빠르게 조정할 수 있었습니다.
