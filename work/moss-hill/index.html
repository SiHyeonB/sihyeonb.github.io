Technical breakdown

Moss Hill의 최종 Level Art와 장면 전반에 활용한 Clover·Piano Stage·Mobile Blueprint의 동작 결과입니다.

제작 범위

제공된 컨셉 아트를 기반으로 Landscape와 Level Art를 구성하고, 캐릭터와 반응하는 Piano Stage, 장면 전반에 반복되는 Clover, 계층형으로 움직이는 Mobile을 제작했습니다.

문제와 제약

Piano Stage는 캐릭터의 움직임에 따라 건반이 반응해야 했지만, 이를 위해 피아노를 별도로 Rigging하거나 Skeletal Mesh·Animation Asset을 추가하고 건반마다 Animation Key를 설정하는 방식은 작업 단계가 많았습니다. 기존 캐릭터 Component에서 얻을 수 있는 정보를 직접 상호작용 입력으로 사용하는 구조가 필요했습니다.

클로버는 넓은 배경에 반복 배치되므로, 형태 조정 방식보다 거리별 Geometry와 반복 Component를 어떻게 관리하는지가 더 중요했습니다. Mobile은 장식 위치가 바뀌어도 연결 구조와 계층형 회전을 다시 조립하지 않고 조정할 수 있어야 했습니다.

Bounds-Driven Interactive Piano

Character Skeletal Mesh Component → Target Bone Bounds → Key State → Per-Key DMI / Timeline → Emissive

캐릭터 Skeletal Mesh Component의 지정 Bone Bounds를 직접 참조해 Piano의 상호작용 입력으로 사용했습니다. 캐릭터의 움직임에서 얻은 Bounds를 건반 상태와 연결하므로, 피아노용 Rigging·별도 Skeletal Mesh Animation·건반별 Animation Key 작업 없이 Interactive 동작을 구성할 수 있습니다.

건반마다 개별 Dynamic Material Instance를 생성해 다른 건반의 상태에 영향을 주지 않도록 분리하고, LightChange Timeline으로 Emissive Scalar·Vector Parameter를 갱신했습니다. Bounds 기반 입력과 발광 로직을 연결해 캐릭터 동작에 따라 건반의 점등과 감쇠가 이어지도록 구성했습니다.

Clover LOD & Instancing

Clover Mesh Variants → Distance LOD → Instanced Static Mesh → Level Placement

클로버는 거리별로 필요한 형태와 Geometry를 구분한 여러 LOD를 구성하고, 장면 전반의 반복 배치는 Instanced Static Mesh로 묶었습니다. 개별 Actor와 Component를 계속 추가하지 않고도 배경의 밀도를 유지하면서, 원경에서는 단순화된 LOD가 사용되도록 정리했습니다.

형태 Variation과 반복 배치 구조를 분리해 필요한 Clover Variant는 유지하고, 동일 Mesh의 대량 배치는 Instance 단위로 관리했습니다.

Procedural Mobile

Location Markers → Wire Connection Update → Hierarchical Pivot Rotation

Beam A·B와 장식의 연결 지점을 Pivot 계층으로 구성하고, 장식 위치가 바뀌면 각 연결점 사이의 Wire가 함께 갱신되도록 했습니다. Mobile 전체를 다시 조립하지 않고 연결 구조와 실루엣을 조정할 수 있는 보조 제작 도구입니다.

런타임에는 Beam A와 B의 회전 입력에 Delta Seconds를 적용해 각 Pivot에 Local Rotation을 누적합니다. 상·하위 Beam과 장식이 계층을 따라 함께 움직이므로 두 단계의 회전값으로 모빌 전체의 움직임을 제어할 수 있습니다.

내 기여

  • 캐릭터 Bone Bounds를 직접 참조하는 Piano 상호작용 입력 구성
  • 건반별 Dynamic Material Instance와 Timeline 기반 Emissive 제어
  • Clover 거리별 LOD와 Instanced Static Mesh 반복 배치
  • 연결점 갱신과 계층형 Pivot 회전을 적용한 Mobile Blueprint
  • Moss Hill 전반의 Blueprint 적용 및 Level Art 조정

검증·성과

Piano Stage는 별도 Rigging·Skeletal Mesh Animation·건반별 Animation Key 없이 캐릭터 Bounds로 상호작용하도록 구성해 시네마틱 제작팀의 반복 작업을 줄였습니다. Clover는 LOD와 ISM으로 반복 배치 비용을 관리했고, Mobile은 연결점과 Pivot 입력만으로 구성과 회전 속도를 조정할 수 있게 했습니다.
