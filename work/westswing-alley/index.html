제작 범위

APOKI MV ‘West Swing’의 Korean Retro Alley Environment에서 라이팅과 일부 프랍을 제외한 환경 제작 전반을 담당했습니다. 좁은 골목의 공간 구성과 건축·상점 에셋, Material, Level Art 및 간판 제어 Blueprint를 제작했습니다.

문제와 설계

좁고 긴 골목 안에서 반복되는 상점과 간판이 하나의 공간으로 읽혀야 했으며, 근접 Shot에서도 벽체와 셔터, 보도와 노면이 단조롭게 보이지 않아야 했습니다. 모든 환경 에셋을 고유 Texture와 개별 Material로 제작하면 제작 범위뿐 아니라 수정·관리 항목도 빠르게 증가하는 구조였습니다.

또한 골목의 인상을 결정하는 다수의 네온 간판은 장면의 색 구성에 큰 영향을 주기 때문에, 개별 Actor와 Material을 반복해서 열지 않고 전체 상태를 빠르게 비교하고 조정할 수 있는 제어 방식이 필요했습니다.

Signage Blueprint Controller

Controller Parameters → Signage Color / Emissive On·Off → Scene Variation

골목 전반에 배치된 간판의 색상과 발광 상태를 하나의 Blueprint Controller에서 조정할 수 있도록 구성했습니다. 여러 간판의 점등·소등과 색상 조합을 함께 변경해, 에셋이나 Material Graph를 개별 수정하지 않고도 장면에 필요한 간판 패턴을 빠르게 비교할 수 있도록 했습니다.

Tiling Surface & Mesh Decal Workflow

Environment Base Mesh → Shared Tileable Surface / Detail Texture → DCC Vertex Color Road Blend → Mesh Decal Detail Pass → Level Art

건축물과 노면의 형태·실루엣은 Base Mesh에서 구성하고, 넓게 반복되는 표면은 공용 Tileable Surface Material과 Tiling Detail Texture로 분리했습니다. 동일한 표면 자산을 여러 건물과 거리 모듈에 재사용해 에셋별 고유 Texture 제작 범위와 Material Variant 증가를 제한했습니다.

접합 경계와 오염, 노면 표식처럼 필요한 표면 정보는 Mesh Decal로 분리했습니다. 공용 Surface를 유지하면서 카메라에 가까이 노출되는 지점에 추가 Detail을 선택적으로 배치해, 별도의 고해상도 고유 Texture를 계속 늘리지 않고도 골목의 표면 밀도와 반복 변화를 확보했습니다.

DCC Vertex Color Road Blending

DCC Vertex Color Mask → Triangle-Aware Topology Optimization → Engine Material Blend

도로 Mesh는 DCC에서 Vertex Color 기반의 Surface Blend Mask를 미리 설정했습니다. Vertex Color가 Triangle 내부에서 보간되는 점을 기준으로, Blend 경계가 필요한 위치에만 Vertex와 Triangle을 배치하고 변화가 없는 구간의 밀도는 줄였습니다. 최종 Triangulation까지 DCC에서 정리한 상태로 Engine에 Import해 의도한 Blend 형태가 유지되도록 했습니다.

Material에서는 해당 Vertex Color를 Mask로 읽어 기본 노면과 젖음·오염 Variation을 혼합했습니다. 도로별 전용 Mask Texture를 추가하지 않고도 DCC에서 필요한 영역을 직접 제어하면서, 표현에 필요한 보간 해상도와 Triangle 수를 함께 관리할 수 있도록 구성했습니다.

내 기여

  • 라이팅과 일부 프랍을 제외한 Korean Retro Alley 환경 제작 전반
  • 골목 공간 구성과 건축·상점 에셋 및 Level Art
  • 공용 Tileable Surface Material·Tiling Detail Texture 구성
  • DCC에서 미리 세팅한 Vertex Color 와 이를 이용한 Road Surface Blend
  • Mesh Decal 기반 표면 Variation 제작·배치
  • 다수 간판의 점등·색상·발광 상태를 조정하는 Blueprint Controller 제작
  • 반복 에셋 Material 및 Texture의 재사용 기준이나 Atlas Texture Layout 정리

결과

공용 표면과 Detail Layer, DCC 기반 Road Blend, 간판 제어를 서로 다른 제작 계층으로 분리해 좁은 골목의 시각적 밀도를 확보했습니다. 최종 환경은 West Swing 뮤직비디오에 적용되었으며, 고유 리소스의 증가를 제한하면서도 장면별 간판 상태와 표면 디테일을 조정할 수 있는 구조로 정리했습니다.
