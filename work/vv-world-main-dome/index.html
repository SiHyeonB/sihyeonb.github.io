VV World의 메인 돔 레벨을 단독 제작했습니다. 대형 곡면 건축과 연결 통로, 실내 허브를 단 두 세트의 POM Trim으로 통합하고, 랜드마크 홀로그램·광고 패널·안내 연출과 같은 VFX 적인 요소들은 Mesh와 전용 Material로 직접 제작해 배경 전반의 형태·표면·연출을 하나의 시스템으로 구성했습니다.

Role

Technical breakdown

메인 돔의 외부·연결 통로·실내 허브를 보여주는 최종 결과입니다. 반복되는 건축 표면은 두 세트의 POM Trim으로 통합했으며, 중앙 랜드마크와 광고·안내 홀로그램은 Mesh와 전용 Material로 직접 제작했습니다.

제작 범위

VV World의 중심 공간으로 사용되는 메인 돔 레벨을 단독 제작했습니다. 공간의 Blockout과 대형 돔 건축, 연결 통로, 실내 허브, 라운지, 배경 소품, Material, 홀로그램 연출과 Level Art까지 배경 제작 전반을 담당했습니다.

외부의 거대한 돔 실루엣에서 내부 중앙 광장으로 자연스럽게 이어지도록 접근로와 고가 통로를 구성하고, 곡선형 구조·식생·발광 안내 요소를 반복해 하나의 장소로 읽히는 시각 언어를 만들었습니다.

문제와 제약

하나의 레벨 안에서 대형 곡면 외벽, 반복되는 구조 프레임, 실내외 연결부와 다수의 안내·광고 요소를 제작해야 했습니다. 각 에셋을 고유 High-Poly Bake와 전용 Texture로 처리하면 제작량과 Texture Memory, Material 관리 비용이 빠르게 늘어나는 구조였습니다.

또한 넓은 외부 전경에서는 돔이 명확한 Landmark로 읽혀야 하고, 가까이 접근했을 때는 반복 모듈이 지나치게 단순하거나 동일하게 보이지 않아야 했습니다. 그래서 실루엣을 담당하는 Base Mesh와 반복 표면 디테일을 담당하는 Trim, 시선을 끄는 홀로그램 요소를 서로 다른 제작 계층으로 분리했습니다.

Two-Set POM Trim Workflow

이 레벨은 일반 패널 표면과 디테일한 Structure 군을 각각 담당하는 두 세트의 일반 POM Trim을 중심으로 제작했습니다. 돔 외피와 벽체, 곡선 프레임, 통로, 바닥 경계와 입구처럼 반복되는 부분을 공통 Trim 규칙에 맞춰 구성했습니다.

Base Mesh는 대형 곡면과 구조적 실루엣, 모듈 결합에 집중하고, 패널 경계·홈·프레임과 같은 반복 디테일은 POM Trim으로 분리했습니다. 같은 두 세트를 외부 쉘부터 내부 허브까지 재사용해 개별 Bake와 고유 Texture 의존도를 매우 줄이면서도 표면 언어를 일관되게 유지했습니다.

Modular Dome Assembly

메인 돔과 연결 통로는 곡선형 프레임, 외벽 패널, 기둥, 입구와 바닥 모듈을 조합할 수 있도록 구성했습니다. 동일한 규격을 반복하되 프레임의 간격과 방향, 통로 폭, 벽체와 식생의 조합을 달리해 외부 접근로·고가 통로·실내 라운지가 서로 다른 공간으로 읽히도록 했습니다.

반복 모듈이 넓은 장면에서 단조롭게 보이지 않도록 중앙 돔을 가장 강한 실루엣으로 두고, 연결 통로와 파이프가 주변으로 뻗어나가는 방사형 구성을 사용했습니다. 내부에서는 중앙 광장과 홀로그램을 시각적 기준점으로 삼아 동선이 자연스럽게 수렴하도록 구성했습니다.

Mesh + Material Holograms

돔 상단의 VV Landmark, 중앙 광장의 도시 형상, 외부의 수직 홀로그램, 광고 패널과 발광 안내 표시는 모두 전용 Mesh와 Material로 직접 제작했습니다. 단순한 평면 이미지 배치에 그치지 않고, 공간의 크기와 카메라 거리에 맞춰 형태와 깊이, 발광 범위가 읽히도록 Mesh 실루엣과 Material 표현을 함께 조정했습니다.

홀로그램은 반복되는 흰색·파랑 계열의 건축 표면에 색상과 움직임이 집중되는 시각적 초점을 만들며, 외부에서는 Landmark로, 내부에서는 방향 안내와 공간 구분 요소로 기능하도록 배치했습니다.

Level Art & Spatial Composition

외부에서는 접근로와 파이프, 홀로그램 기둥이 중앙 돔을 향해 시선을 유도하도록 구성했습니다. 고가 통로에서는 프레임의 반복과 투명한 개방감을 이용해 이동 중에도 돔과 주변 지형이 계속 보이도록 했습니다.

내부 허브는 중앙 홀로그램 광장을 중심으로 라운지와 포드형 입구를 배치하고, 야자수와 저층 식생으로 대형 구조물의 스케일을 보완했습니다. 곡선 구조와 발광 안내 표시를 연속적으로 사용해 서로 다른 구역이 하나의 메인 레벨로 연결되도록 정리했습니다.

리소스 재사용 전략

  • 두 세트의 POM Trim을 외부·통로·내부 모듈에 재사용하여 고유 Bake와 Texture 수를 제한
  • 대형 실루엣은 Base Mesh, 반복 표면 디테일은 Trim으로 분리해 제작 비용 관리
  • 곡선 프레임·벽체·입구·바닥 모듈의 규격화로 신규 Mesh 제작량 절감
  • 반복 에셋은 배치와 조합을 변화시키고, 고유 리소스는 중앙 돔과 홀로그램 Landmark에 집중
  • 홀로그램·광고·안내 요소를 공통 Mesh/Material 제작 규칙으로 구성해 표현과 관리 방식 통일

내 기여

  • 메인 돔 레벨 전체의 Blockout과 공간 구성
  • 돔 외부·연결 통로·실내 허브·라운지 Level Art
  • 모듈형 건축·통로·배경 소품 에셋 제작
  • 두 세트의 POM Trim 제작 규칙 설계와 적용
  • 배경 Surface Material과 발광 안내 Material 제작
  • 홀로그램 Landmark·광고 패널·안내 연출용 Mesh와 Material 제작
  • 리소스 구성과 재사용 기준 수립

결과

대형 외부 Landmark와 연결 통로, 내부 허브가 하나의 시각 언어로 이어지는 VV World 메인 돔 레벨을 완성했습니다. 두 세트의 POM Trim과 모듈형 에셋을 중심으로 대규모 배경의 제작량을 관리하고, 직접 제작한 Mesh/Material 홀로그램을 핵심 지점에 배치해 제한된 리소스 안에서도 강한 장소성과 기술적 차별점을 확보했습니다.
