제작 범위

APOKI ‘Shut Up Kiss Me’의 Desert Castle Stage에서 라이팅을 제외한 Environment Production 전반을 담당했습니다. 무대와 원경 Castle, 반복 배경 에셋, Material, Level Art 및 장면 제작에 필요한 Blueprint를 구성했습니다.

문제와 설계

전면의 공연 무대와 대형 Castle이 하나의 구도에서 함께 읽혀야 했습니다. 특히 넓은 Stage Floor의 Grid는 카메라 각도와 원근에 따라 보이는 간격이 크게 달라졌기 때문에, 고정된 패턴을 그대로 사용하는 대신 Sequencer의 각 Shot에 맞춰 밀도와 위치를 조정할 수 있어야 했습니다.

원경 Castle의 반복 Window 역시 개별 Geometry를 계속 추가하기보다, 제한된 Mesh와 Texture 구성 안에서 반복성과 깊이를 함께 표현할 수 있는 방식이 필요했습니다.

Procedural Diamond Grid Material

UV → X/Y Tiling·Offset → 45° Rotation → Sine·Abs → SmoothStep(R×G) → Grid Mask / Procedural Normal → Material Attributes

Grid Pattern은 별도의 Grid Texture를 샘플링하지 않고 Material 연산으로 생성했습니다. UV의 U·V축에 서로 다른 Tiling과 Offset을 적용한 뒤 45° 회전하고, 두 축의 Sine 파형을 Abs와 SmoothStep으로 정리해 대각선이 교차하는 Diamond Grid Mask를 만들었습니다. Thickness와 Smooth를 분리해 선의 폭과 Edge를 독립적으로 조절할 수 있도록 구성했습니다.

그래프 내부에 Time이나 Panner를 넣어 자동으로 이동시키는 대신, 노출한 Tiling_X/Y와 Offset_X/Y 값을 Sequencer에서 Shot별로 조정했습니다. 덕분에 카메라 구도가 바뀌어도 화면 안에서 Grid의 진행 방향과 밀도를 의도한 형태로 다시 맞출 수 있었습니다.

같은 Sine Pattern에서 더 얇은 Mask를 분리하고 PerturbNormalHQ를 적용해, 별도의 Normal Texture 없이 선 경계의 미세한 표면 굴곡도 생성했습니다. 실제 Geometry를 변형하지 않고 Grid의 재질 반응만 보강한 구조입니다.

POM Atlas Castle Windows

Castle의 반복 Window는 Plane Mesh와 Atlas Texture로 구성하고 POM Material로 깊이를 더했습니다. 반복되는 창문을 개별 Geometry로 제작하지 않고도 원경에서 필요한 입체감과 Pattern 밀도를 유지할 수 있도록 했습니다.

결과

Floor Grid와 반복 Window를 Material 중심의 구조로 분리해, 카메라 구도 변화에 대응하면서도 고유 Texture와 반복 Geometry의 불필요한 증가를 줄였습니다. 최종 Stage는 Shot별 연출 조정이 가능한 상태로 정리했습니다.
