View-Space WPO Perspective Compensation

2026.06

Shader DevMaterial ArtTechnical ArtVertex Offset / Material FunctionCustom Primitive Data

Head Center를 기준으로 캐릭터 Vertex를 View Space에서 재배치하여, 넓은 FOV와 근거리 카메라에서 발생하는 얼굴의 원근 왜곡을 선택적으로 완화하는 WPO Material Function을 구현했습니다.

Role
Perspective Compensation 설계 · Custom HLSL/WPO 구현 · Custom Primitive Data 연동 · Character Material 통합
Project
VV World
Engine
Unreal Engine 5

Technical breakdown

Correction Amount와 Head 적용 범위를 조절하고, 서로 다른 카메라 조건에서 결과를 검증한 장면입니다.

문제와 목표

Perspective Camera에서 넓은 FOV를 사용하거나 캐릭터가 카메라에 가까워지면, 얼굴의 앞뒤 깊이 차이가 과장되어 코와 얼굴 외곽의 비율이 의도보다 크게 변할 수 있습니다. 전체 카메라 Projection이나 캐릭터 스케일을 변경하지 않고, 얼굴 주변 Vertex에만 국소적인 보정을 적용해야 했습니다.

보정 원리

Head Center(CPD) → World/View Space 변환 → Head Depth 기준 재투영 → 영역 Mask·안전 제한 → View-to-World Offset → 기존 WPO에 Add

Custom Primitive Data로 전달된 Head Center와 각 Vertex의 World Position을 View Space로 변환합니다. 이후 아래의 깊이 비율을 이용해 각 Vertex의 View-Space XY Offset을 계산했습니다.

OffsetXY = VertexViewXY × (VertexDepth / HeadDepth − 1)

영향을 받는 Vertex가 Head Center와 유사한 View Depth에 있는 것처럼 XY 위치를 보정함으로써, 얼굴 내부의 깊이 차이에서 발생하는 Perspective Scale 변화를 완화합니다. 계산된 Offset은 다시 World Space로 변환하고 기존 Material Attributes의 WPO에 더해, 다른 Vertex Animation과 함께 사용할 수 있도록 구성했습니다.

적용 범위와 파라미터

Head Center를 중심으로 한 Sphere Mask와 높이 기반 Fade를 곱해 얼굴 주변에만 보정이 적용되도록 했습니다. Mask Radius와 Start/End Height는 Object Scale을 반영하므로 캐릭터 크기가 달라져도 유사한 적용 범위를 유지합니다.

Removal Amount, Mask Radius, Start / End Height, Max Offset, Close Fade Start / End를 노출해 캐릭터와 카메라 조건에 맞게 조절할 수 있도록 했습니다.

안정성과 시스템 통합

Head Depth, Radius와 Height Range에는 최소값을 적용해 0에 가까운 값에서 계산이 불안정해지는 상황을 방지했습니다. 카메라가 지나치게 가까워지면 Smoothstep 기반 Close Fade로 효과를 줄이고, 최종 XY Offset에는 Hard Clamp를 적용해 Vertex가 과도하게 이동하지 않도록 제한했습니다.

Head Center는 캐릭터별 Custom Primitive Data로 전달하고, Function은 Material Attributes를 입력받아 기존 WPO를 보존한 채 보정 Offset만 누적합니다. 이를 통해 캐릭터 Material 구조를 크게 변경하지 않고 공통 기능으로 통합했습니다.

결과

카메라의 Projection과 배경의 원근감은 유지하면서 캐릭터 얼굴에만 선택적으로 보정을 적용할 수 있게 했습니다. 넓은 FOV와 근거리 구도에서도 얼굴 비율을 안정적으로 유지하고, 캐릭터별 파라미터 조절과 기존 WPO 기능의 병행이 가능한 구조로 제작했습니다.
