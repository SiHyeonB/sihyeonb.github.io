Hero Asset - Hover Car Interior, VFX, Blueprint

Hover Car

2021.12

Asset ArtHero AssetMaterial ArtBlueprint

Hover Car의 실내 파트와 Mesh 기반 VFX를 제작하고, 시네마틱 제작팀이 연출에 사용할 수 있도록 Material Parameter와 Blueprint 제어를 연결했습니다.

Role
Hero Asset 실내 파트 제작 · 관련 Blueprint 제작
Project
Apoki 'Shut Up Kiss Me'
Engine
Unreal Engine 4

문제와 제약

차량 외형뿐 아니라 카메라에 노출되는 실내 파트와 연출용 Mesh VFX를 함께 제작해야 했습니다. 효과를 장면에 고정하면 샷마다 수정 지점이 분산되므로, 시네마틱 제작팀이 필요한 상태와 연출 값을 에셋 내부 수정 없이 조정할 수 있는 구조가 필요했습니다.

설계·구현

실내 파트와 Mesh 기반 VFX를 하나의 Vehicle Blueprint Actor 안에 구성하고, 장면에서 반복 조정해야 하는 Material Parameter와 효과 상태를 Blueprint 입력으로 연결했습니다. 제작 요소와 연출 제어를 분리해 Mesh·Material Graph를 다시 편집하지 않고도 씬별 상태를 설정할 수 있도록 했습니다.

실내 파트는 카메라에 노출되는 범위를 기준으로 제작하고, Mesh VFX는 차량 Actor와 함께 배치·관리되도록 구성했습니다. Material Parameter 변경과 효과 상태 전환을 Blueprint에서 처리해 장면별 수정 경로를 한곳으로 모았습니다.

내 기여

  • Hover Car 실내 파트 모델링과 Material 제작
  • Mesh 기반 VFX 및 연출 요소 제작
  • Material Parameter와 Blueprint 입력 연결
  • 시네마틱 제작팀용 Vehicle Blueprint Actor 구성

검증·성과

차량·실내 파트·Mesh VFX·제어 입력을 하나의 Blueprint Actor로 제공해, 씬 배치 후 필요한 상태와 연출 값을 직접 조정할 수 있도록 했습니다. 장면에 고정된 효과를 반복 수정하지 않고 동일 Actor를 샷별 설정에 맞춰 재사용할 수 있는 전달 구조로 정리했습니다.
