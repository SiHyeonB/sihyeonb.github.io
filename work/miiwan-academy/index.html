Technical breakdown

공용 Surface Material, Geometry Nodes Vertex Color, 6-Wave WPO와 Blueprint Controller의 구현 구조 및 결과입니다.

제작 범위

완성된 컨셉 아트가 없는 상태에서 공간의 비주얼 방향과 동선을 구체화하고, 라이팅을 제외한 Environment Production 전반을 담당했습니다. 모듈 18종과 건축물 24종의 에셋·Texture·Material·Level Art·Blueprint를 하나의 제작 규칙으로 연결했습니다.

배경 표면은 4개 Texture Set과 공용 Material 구조로 운영하고, 약 100m 규모의 대형 배경은 WPO와 Blueprint Controller를 이용해 씬별로 변형할 수 있도록 구성했습니다.

문제와 제약

짧은 일정 안에서 형태가 다른 다수의 모듈과 건축물을 제작하면서도, 에셋별 UV Unwrap·Mask Texture·Parent Material이 계속 늘어나지 않는 표면 구조가 필요했습니다. 동일 Material을 반복 적용할 때 드러나는 색상·오염 패턴도 별도 Unique Texture 없이 분산해야 했습니다.

대형 Static Mesh에는 여러 위치의 굴곡이 동시에 필요했고, 변형 구간이 겹쳐도 형태가 끊기지 않아야 했습니다. Mesh를 분할하거나 Skeletal 구조와 개별 Animation Key를 추가하지 않고, 시네마틱 제작 과정에서 위치·범위·강도를 반복 조정할 수 있어야 했습니다.

공용 Material Architecture

기본 Surface는 공용 Material Instance를 사용하고, Floor Atlas와 WPO처럼 추가 기능이 필요한 경우에만 별도 Child Material로 분리했습니다. Surface UV는 생략하고 Decal에만 UV를 사용해, 크기와 형태가 다른 에셋에도 동일한 Tiling Surface를 적용했습니다.

표면 표현은 4개 Surface Function으로 분리해 Material Attributes로 결합하고, Tiling·Decal·Variation의 공통 처리는 Master Material에 유지했습니다. Surface 표현은 개별 Function에서 교체하고, 공통 기능은 Master 한 곳에서 전체 에셋에 반영하도록 구성했습니다.

4개 Texture Set은 배경에 사용하는 표면 리소스의 범위이고, 4개 Surface Function은 Master 안에서 수정 경로를 분리한 Material 구조입니다.

Vertex Color 자동화와 Surface Variation

Geometry Nodes에서 R=AO, G=Variation을 계산해 Vertex Color Attribute에 기록했습니다. Geometry가 변경되면 Graph를 다시 실행해 Mask를 갱신하므로, 수동 Vertex Paint와 Mask Texture 재작업 없이 표면 제어 데이터를 다시 만들 수 있습니다.

G 채널 Mask에 World·Actor Position을 결합하고, Per Instance Random과 Triplanar Noise로 변화 범위를 조정했습니다. 동일 Mesh와 Material을 유지하면서도 Actor별·영역별 표면 차이를 만들도록 구성했습니다.

6-Wave Environment Deformation

Vertex·Actor 위치의 거리로 변형 범위를 계산하고, Radius에 Cosine Falloff와 Height를 적용했습니다. Material Parameter Collection의 A–F Slot에 저장한 6개 Wave를 하나의 WPO Function에서 합산해, 여러 변형 중심이 겹치는 구간도 연속적인 곡면으로 구성했습니다.

Mesh 분할이나 Skeletal 구조 없이 하나의 Static Mesh에서 복수 굴곡을 만들 수 있도록 했습니다.

Blueprint Controller

Wave Number로 Material Parameter Collection의 A–F Slot을 선택하고, Controller의 Location·Radius·Height를 선택한 Slot에 전달했습니다. Controller를 이동하거나 값을 변경하면 결과를 Viewport에서 즉시 확인할 수 있습니다.

Material Graph를 직접 수정하지 않고도 시네마틱 제작팀이 씬별 변형 중심·범위·강도를 설정하고 반복 조정할 수 있도록 제공했습니다.

검증·성과

모듈 18종·건축물 24종을 4개 Texture Set과 공용 Material 구조로 운영해 에셋별 Surface UV·Mask Texture·개별 Parent 제작 단계를 제거했습니다. Geometry 수정 후에는 Geometry Nodes Graph 재실행으로 AO·Variation Mask를 갱신할 수 있도록 했습니다.

6개 Wave를 합성해 하나의 Static Mesh에서 여러 굴곡을 구성하고, 시네마틱 제작팀이 Material 수정 없이 Controller에서 씬별 배경 형태를 직접 조정할 수 있도록 연결했습니다.
