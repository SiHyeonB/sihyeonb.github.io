Data-Driven WPO Animation Internal R&D Prototype

MIDI-to-Texture Vertex Animation Prototype

2026.06

VV World의 데이터 기반 소품 애니메이션 가능성을 검증하기 위해 제작한 내부 R&D 프로토타입입니다. MIDI 연주 데이터를 Time-Series Data Texture로 변환하고, 피아노 메시의 UV 주소와 파츠 Mask를 이용해 88개 건반과 Key–Wippen–Hammer 동작을 하나의 WPO Material에서 구동했습니다.

Role
MIDI Mapping Generator · Data Texture Encoding · UV Address/Mask 설계 · Pivot-Based WPO Material · Blueprint Integration
Project
VV World · Internal R&D Prototype
Engine
Unreal Engine 5

Technical breakdown

MIDI Data Texture로 구동한 피아노 애니메이션 결과와 UV Address, Part Mask, WPO Material 구성입니다.

시스템 개요

이 작업은 VV World의 실제 출시 기능이 아닌, 데이터 기반 소품 애니메이션의 가능성을 검증하기 위해 제작한 내부 R&D 프로토타입입니다.

MIDI 연주 데이터를 Time-Series Data Texture로 변환하고, 피아노 메시의 UV에 저장한 주소와 Mask를 이용해 88개 건반 및 내부 메커니즘을 GPU에서 동시에 구동하는 WPO Animation Pipeline을 제작했습니다.

Animation Data, Mesh Addressing, Mechanical Motion을 분리하여 개별 파츠에 Animation Key를 반복 입력하지 않고도 Data Texture 교체만으로 다른 연주를 재생할 수 있도록 설계했습니다.

문제와 설계

건반과 내부 부품은 서로 다른 Pivot과 회전축을 가지며 Key → Wippen → Hammer 순서로 반응해야 합니다. 88개 건반과 연결 부품을 개별 Animation Track으로 관리하면 수정 범위가 커지고 다른 곡에 재사용하기도 어렵기 때문에, 입력 데이터와 메시의 기계 구조를 분리했습니다.

MIDI → Blender Python Generator → Data Texture → UV Address / Part Mask → Signal Remap → Pivot-Based WPO

Data Texture의 한 축은 시간, 다른 축은 건반 주소로 사용합니다. Material은 Time, Midi Speed, Midi Tiling로 재생 위치를 계산하고, UV2에 저장된 건반 주소를 결합해 각 Vertex가 참조할 Texel을 결정합니다. UV1에는 Key, Wippen, Hammer 등 파츠별 Mask를 저장하여 데이터 주소와 실제 변형 영역을 분리했습니다.

작동 방식

샘플링한 연주 값은 Remap과 Level 조정을 거쳐 각 부품의 회전 입력으로 변환됩니다. 보조 샘플의 Offset을 제어하는 Midi Key Blur를 두어 Texel 전환 경계도 조절할 수 있게 구성했습니다.

Key, Wippen, Hammer는 각각 별도의 Mask, Pivot, 회전축을 사용합니다. Material 내부에서 Rotate About Axis로 계산한 세 회전 결과를 Mask로 조합하고, 최종 Offset을 World Position Offset에 전달해 하나의 입력을 기계적인 연쇄 동작으로 확장했습니다.

재생 Speed와 Tiling, 두 입력값과 각각의 Intensity를 Parameter로 노출했으며, Static Switch로 WPO 경로를 비활성화할 수 있어 제작 및 디버그 시 변형 전후를 분리해 확인할 수 있습니다.

내 기여

  • 88개 MIDI Note와 Data Texture Texel Address의 매핑 규칙 설계
  • MIDI 파일을 Time-Series Data Texture로 변환하는 Blender Python Generator 제작
  • UV1 Part Mask와 UV2 Key Address 규칙 설계
  • Time/Panner 기반 GPU Data Texture Sampling 구성
  • Key·Wippen·Hammer별 Pivot, Axis, Mask를 적용한 WPO 구현

  • Material과 Blueprint에서 재사용할 수 있는 적용 흐름 정리

결과

연주 데이터와 메시의 기계 구조를 분리해 동일한 피아노 에셋에서 Data Texture만 교체하여 다른 곡의 전체 동작을 재생할 수 있음을 검증했습니다. 다수 파츠를 개별 Animation Track으로 관리하지 않고 하나의 Material 기반 구조로 통합하는 제작 가능성과 재사용 흐름을 확인했습니다.
