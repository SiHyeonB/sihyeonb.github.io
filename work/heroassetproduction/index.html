컨셉 아트가 없는 상태에서 시작하여 공용 Mid-Poly + Mesh Decal Workflow를 적용해 Sci-fi Vehicle Hero Asset을 제작하고, Material과 Blueprint를 정리해 애니메이션·콘텐츠 팀이 바로 활용할 수 있는 형태로 제공했습니다.

문제와 제약

뮤직비디오의 주요 차량은 화면에서 반복적으로 크게 노출되기 때문에 실루엣과 표면 디테일을 모두 확보해야 했습니다. 동시에 제작 기간과 실시간 리소스를 고려해 고유 Texture와 복잡한 Geometry의 증가를 통제할 필요가 있었습니다.

해결 방식

주요 형태는 Mid-Poly Mesh로 제작하고, 패널과 접합부 디테일은 공용 Mesh Decal과 Material Library를 활용했습니다. 형태와 표면 디테일을 분리해 디자인 수정에 빠르게 대응하고, 다른 Hero Asset에서도 동일한 제작 규칙을 사용할 수 있도록 했습니다.

내 기여

  • Sci-fi Vehicle Hero Asset 모델링
  • 공용 Mid-Poly + Mesh Decal Workflow 적용
  • Material Instance 및 표면 디테일 구성
  • 애니메이션·콘텐츠 제작팀용 Blueprint 세팅
  • 실시간 사용을 고려한 리소스 구조 정리

Production Handoff

최종 에셋은 Mesh와 Material만 전달하는 방식이 아니라, 콘텐츠 팀이 배치 후 필요한 속성을 조절할 수 있는 Blueprint 형태로 정리했습니다.
