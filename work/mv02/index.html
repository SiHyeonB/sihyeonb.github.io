Role

Technical breakdown

Moss Hill의 최종 Level Art와 장면 전반에 활용한 Clover·Piano Stage·Mobile Blueprint의 동작 결과입니다.

제작 범위

제공된 컨셉 아트를 기반으로 Landscape와 Level Art를 구성하고, 반복되는 자연 요소와 동적 Prop을 빠르게 변형·제어할 수 있도록 세 가지 재사용 Blueprint를 제작했습니다.

문제와 설계

장면 전반에 반복되는 클로버는 배치 위치마다 높이와 휘어짐이 달라야 했고, Piano Stage와 Mobile은 각각 건반 발광과 계층형 회전을 제어해야 했습니다. 개별 Actor 내부에서 Spline·Emissive·Transform을 다시 연결하지 않고, 필요한 값만 입력해 형태와 동작을 조정할 수 있는 구조가 필요했습니다.

Blueprint Systems

Interactive Piano Stage

외부 건반 입력 → 건반별 On/Off·Color → 개별 Dynamic Material Instance → Timeline → Emissive

외부에서 전달되는 건반 입력을 15개의 발광 건반 상태와 연결하고, 건반마다 개별 Dynamic Material Instance를 생성해 다른 건반의 상태에 영향을 주지 않도록 분리했습니다. LightChange Timeline이 선택된 건반의 Emissive Scalar·Vector Parameter를 갱신해 점등과 감쇠가 부드럽게 이어집니다.

개별 건반뿐 아니라 전체 건반, Odd·Even 및 C·F·G 프리셋 그룹과 반복 점등을 함께 제어할 수 있도록 구성해, 하나의 Blueprint에서 여러 발광 패턴을 조정할 수 있게 했습니다.

Spline-Based Procedural Clover

Instance Parameters → Construction Script → Spline Point·Tangent·Scale Update → Stem / Leaf Spline Mesh

줄기와 세 장의 잎을 각각 Spline Mesh로 구성하고, Construction Script에서 파트별 End Location과 Start·End Tangent, Start·End Scale을 갱신하도록 했습니다. 인스턴스별로 높이·휘어짐·잎의 벌어짐·테이퍼를 조정해 하나의 Blueprint로 다양한 실루엣을 만들 수 있습니다.

이 구조를 배경 전반의 클로버에 재사용해, 카메라 구도에 맞춰 개별 형태는 조정하면서도 동일한 제작 규칙을 유지했습니다.

Procedural Mobile

Location Markers → Construction Script → Wire Spline Rebuild → Hierarchical Pivot Rotation

Beam A·B와 장식의 연결 지점을 Pivot 계층으로 구성하고, Construction Script가 각 연결점 사이의 Wire를 Spline Mesh로 재구성하도록 했습니다. 장식 위치를 변경하면 Wire도 연결 구조를 따라 갱신되어 모빌 전체를 다시 조립하지 않고 실루엣을 조정할 수 있습니다.

런타임에는 Beam A와 B의 회전 입력에 Delta Seconds를 적용해 각 Pivot에 Local Rotation을 누적합니다. 상·하위 Beam과 장식이 계층을 따라 함께 움직이므로 두 단계의 회전값으로 모빌 전체의 움직임을 제어할 수 있습니다.

내 기여

  • 건반별 Dynamic Material Instance와 Timeline 기반 Emissive 제어
  • 개별·전체·프리셋 그룹용 Piano Stage 발광 로직
  • Location·Tangent·Scale로 형태를 조정하는 Spline Clover Blueprint
  • 연결점 기반 Wire 재구성과 계층형 Pivot 회전을 적용한 Mobile Blueprint
  • Moss Hill 전반의 Blueprint 적용 및 Level Art 조정

결과

반복되는 형태와 동작을 개별 에셋에 고정하지 않고 Blueprint Input으로 전환했습니다. 동일한 제작 규칙 안에서 클로버 실루엣, Piano Stage의 발광 패턴, Mobile의 구성과 회전 속도를 조정할 수 있어 장면 수정과 바리에이션 제작을 일관된 방식으로 진행할 수 있었습니다.
