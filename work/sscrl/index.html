Screen-Space Rim Light

Character & Environment Post Process Rim Lighting

2026.06

Post Process MaterialShader DevMaterial ArtTechnical Art

Scene Depth, World Normal과 Custom Depth/Stencil을 이용해 캐릭터와 배경의 외곽을 화면 공간에서 검출하고, 실제 Directional Light 방향에 맞춰 2D 스타일 Rim Light를 합성하는 Post Process Material을 구현해 VVWorld 오픈 베타에 적용했습니다.

Role
Character/Environment Screen-Space Rim Function 설계 · Screen-Space Edge Detection · Directional Light 연동 · Post Process 통합
Project
VV World
Engine
Unreal Engine 5

Technical breakdown

캐릭터용 One/Two-Color Rim과 배경용 Directional Rim의 실제 동작 및 스타일 제어 결과입니다.

문제와 목표

일반적인 Fresnel 기반 Rim Light는 View Vector와 표면 Normal에 따라 각 Material 내부에서 계산되므로, 2D 애니메이션처럼 정돈된 두께와 명확한 방향성을 만들기 어렵습니다. 캐릭터와 배경의 개별 Material을 수정하지 않으면서도, 대상별 마스킹과 실제 조명 방향을 유지하는 화면 공간 효과가 필요했습니다.

시스템 구성

Scene Depth / World Normal / Custom Depth·Stencil → UV Sampling Offset → Edge Mask → Light Direction·Distance Correction → Post Process Composite

캐릭터와 배경은 같은 화면 공간 외곽 검출 개념을 공유하지만, 사용할 수 있는 마스크와 필요한 품질 보정이 달라 각각의 Screen-Space Rim Function으로 분리했습니다.

캐릭터용 Screen-Space Rim Light

Custom Depth와 Stencil ID로 적용할 캐릭터를 분리하고, 캐릭터용 Main Light 방향을 UV Sampling Offset으로 변환했습니다. Offset 위치와 현재 Pixel의 Scene Depth 차이로 외곽 Mask를 생성해, Rim이 화면의 임의 방향이 아니라 실제 조명 방향에 대응하도록 구성했습니다.

Rim Width, Threshold, Intensity와 UV Sampling Offset을 조절할 수 있으며, FOV·카메라 거리·Screen Percentage에 따른 Pixel 크기 변화를 보정했습니다. One-Color와 Two-Color Gradient, Gradient Rotation, LookDev용 Light Direction/Color Override를 제공하고, Occlusion 및 추가 Mask를 결합해 가려진 영역과 비대상 영역을 제외했습니다.

배경용 Screen-Space Rim Light

배경용 Function은 SkyAtmosphere의 Directional Light Direction과 Illuminance를 사용해 밝은 방향과 어두운 방향의 Sampling UV를 구성합니다. Scene Depth의 상대 변화량과 World Normal 차이를 함께 사용하여, 깊이 차이가 작은 형태에서도 필요한 외곽을 보완하도록 했습니다.

Near/Far 거리별 Pixel Width와 Gamma 기반 Distance Curve로 원근에 따른 두께 변화를 제어하고, Light/Dark Color, Intensity, Direction Rotation을 독립적으로 조절할 수 있게 구성했습니다. 캐릭터용 Custom Stencil 영역은 제외하여 두 효과가 겹치지 않도록 분리했습니다.

내 기여

  • 캐릭터·배경별 Screen-Space Rim Function 설계 및 구현
  • Scene Depth·World Normal 기반 Directional Edge Detection 구성
  • Custom Depth / Stencil 기반 대상 분리와 Occlusion 처리
  • Character Main Light 및 SkyAtmosphere Directional Light 연동
  • FOV·거리·Screen Percentage 기반 Rim Width 보정
  • One/Two-Color와 Environment Light/Dark 스타일 파라미터 구성

결과

개별 캐릭터 및 배경 Material을 수정하지 않고도 Post Process 단계에서 일관된 Rim 스타일을 적용할 수 있게 했습니다. 캐릭터와 배경에 서로 다른 검출·보정 방식을 사용하면서도 실제 장면의 조명 방향과 일관된 2D 표현을 유지하도록 구성해 VVWorld 오픈 베타의 Character·Environment Post Process 기능으로 반영했습니다.
